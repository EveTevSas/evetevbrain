## Qué se guarda de esta conversación

Se registra la pregunta para saber qué información le falta al asistente y poder
mejorarla. Antes de guardarla se borran automáticamente los datos que puedan
identificar a alguien: correos, teléfonos y números de documento.

El registro se conserva 90 días y se usa solo para mejorar el asistente.

## Qué no hay que escribir aquí

Este chat no es un canal seguro para datos sensibles. No se deben escribir números
de tarjeta, contraseñas ni documentos de identidad. Para cualquier trámite con
datos personales, el canal es contacto@evetev.com.

## Qué es este asistente

Es un asistente automático que responde **solo** con información de una base
documental escrita por el equipo de Evetev. Cuando algo no está en esa base, lo
dice y pasa la conversación a una persona. No toma decisiones, no accede a cuentas
y no ejecuta operaciones.
